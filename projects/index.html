Projects

   oxblood - AI music-video editor with directorial intent. Turns a song plus raw footage into a finished video where every cut lands on the beat, driven by an analyze-plan-execute agent loop you can steer with plain sentences.
   marionet - Testbed for fully agentic solutions. An MCP-based agent with shell, filesystem and browser access, governed by a permission-policy engine and a per-client Docker sandbox with default-deny egress.
   ContextCopilot - Context engine for real-time conversation copilots. Decides whether a turn deserves an answer and assembles the context for it, with a dependency-free core and injected LLM adapters.
   Conversational State Engine - Persistent behavioral state for LLM agents (in development). The state layer owns the agent's behavior through a deterministic policy layer; the LLM only decides wording.
